ぽっと通話の界隈Q&A（利用者から）

これは公式マニュアルではありません。利用者の側から「そもそも、それ何？」を集めた非公式の Q&A です。スマホアプリの世界の言葉だけで説明します。画面の操作や仕様の正確なところは、使い方としくみを見てください。

そもそも編

そもそも、これは何をするアプリなんだい？
通話や会話ができます。他にもちょっとだけ色々。同じ部屋名を開いた人同士が声で話せる場所です。文字の「ひとこと」や絵文字のリアクション、聞いている人（リスナー）が集まれる配信部屋、プログラムが相手をしてくれる BOT の部屋なんかもあります。まずは「声で話せる場所」だと思ってください。
アプリをインストールするの？
しません。Web ページです。ブラウザで開くだけで通話できます。ホーム画面に置けば、見た目はアプリっぽく使えます。
スマホでも大丈夫？
大丈夫です。
アカウント登録や電話番号はいる？
いりません。名前と絵文字をその場で決めるだけ。LINE のような「友だち」もフォローもありません。
お金はかかる？
かかりません。個人の開発者が実験として公開しているプロジェクトです。「運営会社」は存在しません。
LINE や Discord の通話と何が違うの？
大きく2つ。①部屋は「名前を知っていれば誰でも入れる」公開制で、グループを事前に組む形ではないこと。②声が運営会社のサーバーを経由しない作りなこと（詳しくは「通話の仕組み編」）。

部屋とロビー編

「部屋」って何？
同じ部屋名を開いた人同士が集まる場所です。部屋名は住所のようなもので、リンクや QR コードで相手に渡せます。
秘密の部屋は作れる？
作れません。それがこの場所の約束事です。通話中の部屋はすべて、ロビー（画面では「通話中の部屋」という一覧）に出ます。誰がどこで話しているか隠せない、という設計になっています。
知らない人が入ってきたんだけど？
部屋は公開が前提です。身内向けにしたい場合は、まずロビーから入ってくる前提で考えるのが安全です。
誰もいないはずなのに部屋が立ってる？
BOT（プログラムの参加者）が常駐している部屋があります。案内役、やまびこ（言ったことを返してくれる）、キャラクターBOT など、人がいなくても部屋が立ち続けることがあります。
会話したいのに、人がいない。
しばらく BOT で遊んで時間つぶしてね。ロビーに出ている BOT の部屋（やまびこの部屋や、キャラクターBOT の部屋）なら、ひとりでも声を出して試せます。自分の部屋を立てて待ちたい場合は、ロビーの「新しい部屋ができたら音で知らせる」をオンにしておくと、動きに気づきやすくなります。

通話の仕組み編

声はどこを通って届くの？
声はお互いのブラウザの間を、暗号化したまま行き来します。途中に運営のサーバーはなく、中継は Cloudflare の TURN を使います。
じゃあサーバーは無いの？
運営のサーバーはありません。相手探しは公開の Nostr リレー、声の中継は Cloudflare の TURN で、どちらも運営の機器ではありません。
通話は録音・保存される？
アプリに録音の機能はなく、声がサーバーに残ることもありません。ただし、参加者が自分の側で録音すること自体は技術的に可能なので、そこはマナーの話になります。
回線が弱いとどうなる？
回線の良し悪しがそのまま出ます。環境によっては、うまくつながらないこともあります。

プライバシー編（ここがこの通話の特色）

「IP が見える」ってどういうこと？
IP はインターネット上の住所のようなものです。直接つながる形の接続では、声と一緒にその住所が相手に見える状態になることがあります。次の TURN は、それを避けるための中継です。
TURN って何？
声を中継地点経由で届ける仕組みです。たとえるなら私書箱で、相手に見えるのは中継地点の住所だけになります。ぽっと通話は標準でこの中継（Cloudflare の TURN）を使う設定になっています。
TURN を使えば完全に匿名なの？
相手に見えない、というだけです。「誰にも何も分からない」ではありません。接続を助ける仕組みの側には、通常の通信としての記録が残りえます。ここは正確に理解しておくのが大事です。
名前は本名じゃないとダメ？
自由です。その場で使う名前で構いません。

界隈編（利用者たちが広げているもの）

キャラクターBOT って何者？
利用者が作った、キャラクターとして振る舞う BOT です。決まった台詞や声で応援してくれる、方言で相づちを打つ、など作り手ごとに性格が違います。人ではなくプログラムが部屋に常駐しています。
テキストの BOT の言葉を声で聞ける？
聞けます。CLI 版には読み上げ（TTS）のオプションがあり、VOICEVOX や COEIROINK といった読み上げエンジンを自分のパソコンで用意して設定すると、届いたコメントを手元で読み上げてくれます。エンジンと声は聞く人が自分で用意して選ぶ方式なので、BOT 側が声を流すのではなく、聞く人の手元で声になります。
パソコンのコマンドで入る人もいるの？
います。「CLI 版」と呼ばれる、ブラウザではなくパソコンのコマンド操作で通話に入る道具が有志によって作られています。同じ部屋で、ブラウザの人とも BOT とも一緒になれます。本家の Web 版とは別の、利用者側の派生プロジェクトです。
スマホに通知が来ないの？
アプリではないので、画面を閉じたあとの通知は仕組み上むずかしいのが現状です。開いている間の利用が基本形。利用者の側では「自分の部屋が立ったらスマホに知らせる」といった試みも行われています。
困ったときはどこに聞けばいい？
大手サービスのようなサポート窓口はありません。次の「玄人向け編」にある掲示板が、利用者同士で助け合う場所になっています。

玄人向け編

質問やバグ報告はどこへ？
まずは外部の掲示板「ぽっと通話 ご意見・質問ばん」へどうぞ（アプリの「これはなに？」からも行けます。アカウント不要・匿名 OK）。「Issue を作るほどではない」軽い質問や、ちょっとした不具合の相談はそちらが向いています。しっかり再現手順を書ける上級者は、本家の GitHub リポジトリの Issue へ。「使った端末とブラウザ」「何をしたらどうなったか」があると、作り手が再現しやすくなります。実験プロジェクトなので、直る保証や期限はありません。CLI 版や BOT など利用者側の派生物については、それぞれの置き場所（リポジトリ）へどうぞ。
