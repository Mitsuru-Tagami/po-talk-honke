プッシュ購読テスト

これは ぽっと通話（PWAプッシュ実験版）の、通知の受け口を確かめるための実験ページです（非公式フォーク）。

手順：iPhone の Safari でこのページを開き、共有メニューから「ホーム画面に追加」してください。できたアイコン（購読テスト）から開き直すと、購読できるようになります（iOS の Web Push はホーム追加した PWA が対象です）。
「購読する」を押すと通知の許可を求められます。表示された購読 JSON は、自分の送信役ユニットにだけ渡してください（この JSON は、その端末へ通知を送るための鍵にあたります）。
